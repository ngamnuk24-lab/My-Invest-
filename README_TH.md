# My Invest PWA v1.1 — แท็บทรัพย์สินตั้งต้น

- คง Dashboard, Donut, บันทึกซื้อ/ขาย/ปันผล, Watchlist, ปรับราคาด้วยตนเอง และสำรอง/กู้คืน JSON
- เพิ่มแท็บ “ทรัพย์สินตั้งต้น” สำหรับยอดหุ้น/กองทุนที่มีอยู่ก่อนเริ่มใช้แอป
- ระบุจำนวนหน่วย ต้นทุนเฉลี่ยต่อหน่วย ราคาอ้างอิง ณ วันเริ่มต้น สกุลเงิน FX และวันที่อ้างอิง
- หลังวันตั้งต้น ให้บันทึกการซื้อ/ขายที่ทำผ่านโบรกเกอร์หรือช่องทางอื่นในแท็บซื้อขาย
- ใช้ยอดตั้งต้นรวมกับรายการ BUY/SELL หลังวันตั้งต้น คำนวณต้นทุนคงเหลือ กำไร/ขาดทุนยังไม่รับรู้ และกำไร/ขาดทุนจากการขายแยกตามสินทรัพย์
- รายการซื้อขายก่อนวันตั้งต้นของสินทรัพย์นั้นจะไม่ถูกนำมาคำนวณซ้ำ
- ห้ามบันทึกยอดทรัพย์สินตั้งต้นซ้ำเป็น BUY เพราะจะนับจำนวนและต้นทุนซ้ำ

## สูตรโดยสรุป
- ต้นทุนตั้งต้น = จำนวน × ต้นทุนเฉลี่ย × FX
- BUY เพิ่มจำนวนและต้นทุนรวมค่าธรรมเนียม
- SELL คำนวณกำไร/ขาดทุนด้วยต้นทุนเฉลี่ยถ่วงน้ำหนัก
- Unrealized P/L = มูลค่าตลาดปัจจุบัน − ต้นทุนคงเหลือ
- Realized P/L = กำไร/ขาดทุนสะสมจากรายการขาย
- ผลต่างราคาจากวันตั้งต้นใช้จำนวนตั้งต้นที่ยังถือโดยประมาณ จึงไม่ใช่ Total Return และอาจคลาดเคลื่อนหากขายแล้วซื้อกลับ

## ข้อจำกัด
- ราคาและ FX ต้องกรอกเองหรือเชื่อม API ผ่านการตั้งค่าเดิม
- เก็บข้อมูลในอุปกรณ์ (IndexedDB) ไม่มี cloud sync
- ใช้ average cost ไม่ใช่ระบบบัญชีภาษีที่สมบูรณ์
- ควรสำรอง JSON ก่อนเริ่มใช้งานและก่อนย้ายอุปกรณ์
- โฮสต์บน HTTPS แล้วเปิดครั้งแรกออนไลน์เพื่อให้ Service Worker แคชไฟล์ จากนั้น Add to Home Screen
