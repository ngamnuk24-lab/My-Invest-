ตั้งค่าและข้อมูล

เชื่อมต่อผู้ให้บริการราคาหุ้น (API)

ต้องมี API endpoint ที่รองรับการเรียกจากเบราว์เซอร์ (CORS) และ API key จากผู้ให้บริการที่มีสิทธิ์ใช้งานตลาดนั้น ๆ ก่อน จึงจะดึงราคาอัตโนมัติได้
รูปแบบที่รองรับ: URL ต้องมี {symbol}; ระบบอ่าน JSON เช่น {"price":123.45,"currency":"USD"}

สำรองและกู้คืนข้อมูล

ส่งออกข้อมูลเป็นไฟล์ JSON เพื่อเก็บสำรอง หรือย้ายไปอุปกรณ์อื่น
